# book-talk · 家长和孩子聊书的 AI 教练

**一个 Claude skill：帮家长和孩子好好聊一本书，一次问一个好问题。**

和孩子聊书，多半停在「讲了什么」。难的是在对的时候问一个好的「为什么」，再接一句对的追问。book-talk 替你把书吃透、把问题排好，聊的时候一句一句提示你：你来问，孩子来想，Claude 在旁边帮你接住。

这个 skill 来自我们家几周真实的聊书（孩子 9 岁，英国 Year 5），哪些做法有效、哪些没用，都按实际情况改过。

## 它做什么

1. **备书**：人物、关键情节（标章节）、作者的写法选择、两边都说得通的问题。公版书直接读原文；其他书先请家长核对几条情节。**不编情节。**
2. **围绕一个重点排题**：你说最想让孩子哪方面进步，或者由它建议一个。先排两三个「搭桥」问题，从孩子已经擅长的地方出发、走到这个重点，再从九类问题里补齐 8–10 个，从浅到深。
3. **现场提示**：每一轮给你一句可以直接念的问题、两级提示、「好答案大概会说到什么」。
4. **聊后总结**：孩子今天朝重点走了哪一步、下次从哪儿接着带、需要帮的、她自己总结的读法、不认识的词，以及一个月后原样再问的两个问题。

## 两种用法

| 模式 | 什么时候 | 时长 |
|---|---|---|
| 读完长聊 | 刚读完一本书 | 25–35 分钟，8–10 题 |
| 边读边聊 | 读到一半，或书长、书难 | 每章 5–10 分钟，3–4 题，不剧透 |

## 九类问题

开场（哪里喜欢、哪里没看懂）· 用自己的话概括 · 人物为什么这样做、怎么变的 · 一个词 · 一个画面（先想象，再看作者用的词）· 作者为什么这样安排 · 立场题（先预告「我要反驳你了」）· 连接（自己、别的书、世界）· 收尾（你是怎么想出来的）

## 几条规矩

- 聊书是为了帮孩子，不是考她。每次聊一个重点；孩子说出好东西时，先顺着往重点推一步，再换下一题。
- 一次只问一个问题，接着孩子的话往下问。
- 问要想的，不问要背的。
- 卡住了按梯子给提示，不讲课；真要给答案，也把怎么推出来的说给她听。
- 孩子没看懂大意或关键词时，先讲清楚再问。
- 孩子说「更有意思」「他很生气」这类笼统的话时，给两三个意思相近的词让她挑，帮她把意思说准。这不算纠错。
- 不用术语，不打分，不改语法。

## 安装和使用

- **Claude Code**：把 `book-talk/` 文件夹复制到 `~/.claude/skills/`。
- **Claude.ai**（Pro、Max、Team、Enterprise，需打开 code execution）：在 Settings → Capabilities 上传 `book-talk.zip`。
- 用的时候直接说：「我们来聊书，孩子 8 岁，刚读完 *Charlotte's Web*，请用中文提示我。」

## 由家长主持

Claude 的个人版条款要求使用者满 18 岁，所以设计上由家长使用，孩子不碰 AI。这也正是用意：聊书是家长和孩子之间的事，Claude 只帮你准备、提示下一句。

## 隐私

不要告诉 Claude 孩子的全名、学校这类可识别信息；总结留在自己设备上。skill 本身不存任何数据。
